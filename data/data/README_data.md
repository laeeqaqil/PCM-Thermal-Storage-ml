# Data

The raw experimental dataset from the dual-bank PCM thermal energy storage system
(20 experimental runs across two seasons) is not included in this repository.

Processed/derived features used for model training are generated by the notebooks
in `notebooks/`. If you need access to the raw dataset for collaboration or review,
please contact:

**Laeeq Ahmed Khan Aqil** — layeeqaqil@gmail.com

## Variables in the raw dataset (description only)
- Time (min)
- Solar irradiance (W/m²)
- Ambient temperature (°C)
- Collector inlet/outlet temperature (°C)
- PCM bank 1 / bank 2 temperature (°C)
- Chamber temperature (°C)
- Relative humidity (%)
- Thermal efficiency (%)
